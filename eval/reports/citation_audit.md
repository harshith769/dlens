## Not fixable by the helper (left unchanged)

- **column card (SQL), star pass-through**: the card cites the `select *` line that passes the column through, so the cited line doesn't contain the name. The range is kept. When the column is named nowhere in the model's statement (16 cards), the ledger cites it at **`level: star`**, the level S4's provenance gives the same citation, and metrics M7 checks the lines for `*` (pre-merge fix, S11). The other 3 name their column elsewhere in the statement, inside a window or an expression (`int_customer_order_history.order_date` / `customer_id`, `fct_order_margins.net_revenue`), so the star rule doesn't apply and they stay at `level: line`.
- **model chunk (SQL)** with no entity name: `fct_payment_events` is a one-line `select * from {{ ref(...) }}`, and a 40-line fallback window of `fct_customer_cohorts` holds only its `from` / `join` / `group by` clauses. A chunk's range is its own text, and widening it would cite lines the model was never shown.
